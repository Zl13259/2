方法边界与 Score v0

客观量价研究，不读取持仓，不做账户级仓位核定，不把技术分包装成收益承诺。

因果时间合同

只使用截至 t 日收盘已完成的数据形成日K信号，最早在下一交易时段执行。盘中未完成K线不参与 Q。摆动低点必须有右侧K线确认，不能把信号回填到事后最低点。v11.1 的盘中突破预告仅做条件试算，不形成正式信号或前向样本；预估入场区、止损与目标在收盘后重新冻结。

决策链

日线：数据质量 → 三通道 → 冻结交易几何 → Q / E → 开盘研究模型
盘中：盘前预案 → 新鲜报价 → 结构有效 → 连续价格确认＋量能节奏 → 现价净赔率＋可成交 → 首次触发留痕 → 独立前向结算
账户：风险预算÷止损幅度 → 环境／事件仓位折扣与账户红线人工复核

三通道

  • 超跌反弹：近10日出现超跌，随后有企稳证据，当前反弹触发且超跌低点未失效。
  • 趋势回踩：MA20/MA60 与斜率确认原趋势，回踩明确支撑后重新转强。
  • 突破确认：前20日基底与压力明确，价格、收盘位置和量能共同确认，RS 相对同市场参考基准计算。

交易几何

入场区、止损与目标由触发时的结构锚点固定，不随当前价格移动。净赔率计入费用与双边滑点假设；1.5 是研究门槛，不是正期望的数学证明。目标与止损同时展示百分比和 ATR 距离；ATR 空间提示不是新增门槛，压力近时应降级或放弃，而非拉远目标。止损是计划价，不保证跳空或涨跌停时成交。

净赔率 = 目标净收益 ÷ 止损净损失
S = 0.60 × Q + 0.40 × E（只作同通道启发式基线）

硬门槛

数据不足或陈旧、通道未成立、结构失效、几何非法、净赔率不足、流动性不合格、疑似涨停不可成交，均不能被高分抵消。实际开盘与盘中入场另检查止损距离：低于0.5 ATR或高于2.5 ATR均拒绝执行，不移动结构止损。价格离开入场区只改变执行状态，不允许追价；环境状态单列，不乘入 Q/E/S。

双执行模型与当日生命周期

开盘研究模型继续按实际开盘价检查，突破1次、超跌2次，用于和既有历史回放保持可比。盘中执行模型独立运行：盘前不生成隔夜挂单；连续竞价时，报价不得超过180秒，突破须在有效期内，超跌还须先测试入场区下沿后收复；至少2次连续区内有效报价，间隔45～600秒且未走弱，同时当日量能节奏达到20日全日节奏基准的0.8倍。上述是 Intraday v1 的待验证初始参数，不是已证明最优规则。开盘窗口耗尽不自动否决盘中模型，结构失效则两者都否决。盘中首次五门通过只记录一次，订单口径仅当日有效，收盘未触发自动作废。

成交后研究口径

T+1／3／5／10 均指入场后的对应交易日。策略实际固定期限在提前退出后锁定实际净R；反事实路径假设不退出，只用于研究止损后收复与目标后继续上涨。MFE／MAE 由日K高低价估计，同日先后不可知；首次触及日均以T+0为入场日。历史末端不足持有期的TIMEOUT属于右删失，不得当作已完成交易。

前向证据与版本簇

严格纯前向同时要求 recordOrigin=PRE_ENTRY、savedAt 存在、dataAsOf=triggerDate，并在同一策略版本与交易模型参数簇内按经济信号去重。扫描数量不属于交易模型参数；页面展示升级不重置策略簇，旧档案缺少策略版本时按 legacy:页面版本隔离。不同策略版本不混合计算绩效；全量跨版本档案只用于审计和导出。

高周期压力

只使用触发日前已经完成的周线和月线摆动高点，当前未完成周/月不参与。若最近高周期压力位于原第一目标之前，则将第一目标收缩到该压力并重算净赔率；日线是否触发不由高周期压力反向改写。

验证边界

页面内回放是当前加载池上的探索性研究，不含完整历史股票池、退市样本、滚动样本外、净化隔离和多重试验校正；也未建立组合级并发持仓、资金占用或权益曲线。停牌缺口与逐笔流动性无法由日K完整还原，一字跌停只是保守成交约束，不等于完整市场冲击模型。样本少于30笔显示“样本不足”；达到30笔也不自动等于稳定规律。回放与 v10.2 起新建前向记录覆盖原信号有效期内的回区开盘；旧前向记录仍按原单次口径结算，不混写。

交易日一致性

参考基准先并行核验多源完成日K与报价交易日，采用可佐证的最新完成日；多源冲突无法裁决或市场级陈旧时，整市场停止生成信号。个股最近完成日K必须与该基准一致，不一致时继续降级数据源，仍不一致则列为数据异常。缓存同样接受交易日复核，不以旧基准反向锁死新数据。

  2. 几何非法或净赔率非正值时统一显示“—”；现价破止损改明示“已破止损”，不再丢失方向或显示无意义0.00∶1。

  4. 新增整个冻结入场区最优净赔率预筛；先天无法达到1.5∶1的信号默认退出主列表，可在“预筛剔除”中单独核查。
  5. 新增“盘中突破观察·明日候选预告”，以当前报价试算既有突破条件，展示收盘价格、全日量能、收盘位置与下一交易日预估几何；不提前生成信号或前向样本。
  6. 趋势回踩仍为影子通道；未新增压力收复通道，未放宽净赔率、入场区、连续确认或追价限制。

v11.0 正式版 · 2026-10-28

  1. 体系级拆分开盘研究模型与盘中执行模型，消除“窗口耗尽仍提示买入”和“盘中回区永不形成买点”的口径冲突；结构失效仍为共同否决项。
  2. 盘前只形成预案，不生成隔夜挂单；盘中按数据、结构、确认、交易几何、可成交五门执行，预案仅当日有效，未触发收盘作废。
  3. 新增真实报价样本链：报价时间未推进不算新样本；至少2次连续区内确认、报价新鲜度、日内量能节奏、冻结净赔率和涨停可成交性共同把关。
  4. 突破检查持续保持在突破区且未走弱；超跌要求日内测试入场区下沿后收复，避免把下跌过程直接当反弹买点。趋势回踩继续只做影子研究。
  5. 首次五门通过自动保存不可变触发快照，包括公开报价、确认证据、触发Q／E、盘中E、冻结几何、参数指纹与版本；同一经济计划不重复建档。
  6. 新增独立 Intraday v1 前向结算与汇总，按首次触发报价模拟入场并计成本；与开盘前向及历史回放完全分离。没有分钟级历史数据时不伪造盘中历史绩效。
  7. 盘中结算不利用入场日完整日K倒推触发后的退出或MFE／MAE，统一从下一完成日K开始；保留右删失、跌停不可退出与样本不足边界。
  8. 主表新增五门状态、逐项证据、触发留痕和仅当日有效提示；默认筛选与排序可优先查看盘中通过项，新增独立导出和清空功能。
  9. 69项内核自测通过，另有前向口径审计；自测只验证程序不变量，不证明盘中策略收益。
